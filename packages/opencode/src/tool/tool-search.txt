Search for available tools by name, description or capability. Most tools are not loaded into the conversation up front — use this whenever the task needs a capability you do not currently have a tool for.

Search with the capability you need, not with the concrete arguments you plan to pass.

Examples:

- "search for all the files in the subdirectory XYZ" -> tool_search("search files")
- "list all the files in ../src" -> tool_search("list files")
- "find all issues in repository xxx/yy" -> tool_search("find issues")

How NOT to use it:

- "search for all the files in the subdirectory XYZ" -> tool_search("XYZ")
- "list all the files in ../src" -> tool_search("../src")
- "find all issues in repository xxx/yy" -> tool_search("xxx/yy")

Tools returned by a search stay available for the rest of the session, so you can call them directly on your next step.
